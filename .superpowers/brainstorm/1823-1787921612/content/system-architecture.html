Server-authoritative Roblox architecture

The client makes clicking feel immediate, but only the server can change coins, rebirths, upgrades, or saved data.

Player Client

ClickControllerDetects mouse/touch input on the assigned 3D cookie and plays local squash, sound, particles, and floating numbers.
HUDControllerRenders coins, click power, rebirth progress, boosts, and save-status feedback from replicated state.
StationVisualControllerDisplays Chocolate Chip, Golden, or Cosmic visuals based on the server-provided tier.
Click request→State update

Roblox Server

StationServiceAssigns one station per player and verifies that clicks target the correct station within interaction range.
EconomyServiceRate-limits requests, calculates rewards, purchases upgrades, and exposes safe state snapshots.
RebirthServiceChecks scaled quotas, applies automatic rebirths, preserves overflow, resets temporary upgrades, and advances visuals.
PlayerDataServiceOwns profiles, migrations, autosaves, retries, session locking, and shutdown saves.
Validated profile↔UpdateAsync

Persistent Data

DataStore profileSchema version, coins, rebirths, upgrades, permanent bonuses, unlocked visuals, statistics, and last-save time.
Shared configurationCookie tiers, quota formula, upgrade catalog, producer catalog, rate limits, and balancing constants.
Leaderstats mirrorRead-only display of rebirths and lifetime coins; never used as the source of truth.
Security boundary: the client sends only “I clicked my station.” It never sends coin amounts, multipliers, rebirth counts, prices, or save data.

Failure behavior and verification

Resilience
  • Reject malformed, too-fast, distant, or wrong-station clicks.
  • Retry transient DataStore failures with backoff.
  • Keep profiles server-owned and prevent duplicate sessions.
  • Autosave periodically and save during player removal/server shutdown.
Test coverage
  • Unit-test reward, quota, overflow, upgrade, and visual-tier formulas.
  • Integration-test click → reward → rebirth → save/load.
  • Exploit-test spoofed values and RemoteEvent spam.
  • Playtest multiplayer station ownership on desktop and mobile.
